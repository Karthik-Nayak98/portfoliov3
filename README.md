## ⚙️ Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Installation & Setup

```
$ git clone https://github.com/Karthik-Nayak98/portfoliov3.git

$ cd portfoliov3

$ npm install

$ npm start
```
